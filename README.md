基于RFM模型的电商客户价值分析系统，通过对客户交易数据进行深度挖掘，实现精准客户分群和个性化营销策略推荐。

## 📊 项目概述

本项目针对电商平台的客户交易数据，运用RFM分析模型，将客户划分为7个价值层级，并为每个群体制定差异化的营销策略，助力企业实现数据驱动的精准营销。

### ✨ 核心功能
- 📈 **RFM评分系统**：从最近购买、购买频次、消费金额三个维度评估客户价值
- 🎯 **智能客户分群**：基于机器学习算法将客户划分为7个精准层级
- 📊 **多维度可视化**：生成交互式图表展示客户价值分布
- 💡 **策略推荐引擎**：为每个客户群体生成个性化营销方案
- ⚡ **高性能处理**：支持大规模数据集的高效分析
